# 维护、备份与排障

## 1. 日常改配置

| 想改的东西 | 怎么改 | 要不要重新部署 |
| --- | --- | --- |
| 群友用的跑团口令 | 改 `GROUP_CODE` 环境变量（云平台控制台或 `config.env`） | 要重启/重新部署 |
| 初始化口令 | 改 `ADMIN_SETUP_CODE`（只在没有任何管理员账号时才有用） | 要重启/重新部署 |
| 管理员密码 | 负责人登录 →「账号管理」→ 填新密码 →「重置密码」 | 不用，且该账号旧登录立即失效 |
| 添加/移除管理员 | 负责人登录 →「账号管理」 | 不用 |
| 上传大小上限（6 MB） | 同时改 `src/RunClub.tsx` 和 `server/index.mjs` 里的 `6 * 1024 * 1024` | 要重新构建镜像 |
| OCR 选数规则 | 改 `src/ocr-candidates.ts` | 要重新构建 |

轮换 `GROUP_CODE` 后，群友需要重新输入新口令，旧口令立即失效。

## 2. 备份

### 2.1 自己的服务器 / 本地

```bash
mkdir -p backups
docker compose -f compose.ghcr.yaml exec -T app tar czf - -C /data . > backups/runclub-$(date +%F).tar.gz
```

恢复：

```bash
cat backups/runclub-2026-10-30.tar.gz | docker compose -f compose.ghcr.yaml exec -T app tar xzf - -C /data
docker compose -f compose.ghcr.yaml restart app
```

备份文件里有数据库和群友截图，**不要发微信群、不要提交到 Git**。

### 2.2 免费云平台（ClawCloud / Railway）

平台卷一般不提供网页下载，能做的是：

1. 负责人登录站点，访问 `/api/admin/export` 下载 JSON（全部投稿记录、账号、审核状态），每月存一份到自己电脑。
2. 截图本身不导出，重要月份可以逐个在审核页另存。
3. 真想长期用，尽早按 [方案三](03-服务器部署.md) 迁到自己的服务器。

## 3. 截图占空间

- 被驳回的截图会立即删除。
- 同月同昵称的新成绩通过后，旧的截图会被删除。
- 已通过的截图会一直保留（管理员审核时可以点开核对原始截图）。一卷 1 GB 大约能放 300–500 张手机截图；空间满了可以：

  ```bash
  docker compose -f compose.ghcr.yaml exec app sh -c 'ls -l /data/images/runs/*/* | wc -l'
  ```

  然后按月份删掉最老的目录（先备份数据库再删）。

## 4. 排障对照表

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 打开站点是 404 / 空白 | 镜像没起起来，或 `dist` 不存在 | 看 `docker compose logs app`；本地确认 `npm run build` 能过 |
| `/api/health` 正常，但提交时提示「请从本站页面操作」 | `PUBLIC_ORIGIN` 与实际访问地址不一致 | 把 `PUBLIC_ORIGIN` 改成浏览器地址栏里的完整 `https://域名`，或删掉这个变量 |
| 提交提示「跑团口令不正确」 | 群友输入的口令和 `GROUP_CODE` 不一致 | 核对是否有多余空格；改完变量要重启 |
| 管理员登录后一刷新就退出 | 站点是 http 访问，或反代没传 `X-Forwarded-Proto` | 用 https 访问；Caddy 部署默认没问题 |
| 上传提示图片过大 | 超过 6 MB | 让群友截图后裁一下，或按上表改上限 |
| OCR 一直转圈 | 首次要下载约 30 MB 中文模型，弱网慢 | 让群友换 WiFi 试一次，模型会缓存 |
| 重启后投稿和账号都没了 | `/data` 没挂持久卷 | 按平台教程加卷，Mount Path 必须是 `/data` |

## 5. 迁移平台（ClawCloud → 服务器 之类）

1. 新平台按同样的 4 个环境变量部署，但**先不要把地址发群**。
2. 把旧平台 `/data` 整包拷到新平台（见 [方案三第 7 节](03-服务器部署.md)）。
3. 用旧的管理员账号登录新地址，确认待审核列表、榜单都在。
4. 手机上完整走一遍提交流程。
5. 确认后把新地址发群，旧平台再停。

## 6. 重置负责人密码（忘记密码且没有其他管理员）

普通管理员无法重置负责人密码。可以用 `node` 在容器里直接改数据库：

```bash
docker compose -f compose.ghcr.yaml exec app node -e '
const { DatabaseSync } = require("node:sqlite");
const { pbkdf2Sync, randomBytes } = require("node:crypto");
const db = new DatabaseSync(process.env.DATA_DIR + "/runclub.sqlite");
const salt = randomBytes(16).toString("hex");
const hash = pbkdf2Sync(process.argv[1], Buffer.from(salt, "hex"), 100000, 32, "sha256").toString("hex");
db.prepare("UPDATE admin_accounts SET password_hash=?, password_salt=? WHERE is_owner=1").run(hash, salt);
db.close();
' '你的新密码至少12位'
```

改完刷新页面，用新密码登录。
